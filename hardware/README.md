# Hardware

3D-printable enclosure and optical mounts for MonoSpectro.

Designed in Fusion 360. Neutral exports (STEP for editing, STL for printing) go here
so the design can be used without a Fusion licence.

> Not published yet — see the roadmap in the main [README](../README.md).

| --- | --- |

| `grating_mount.stl` | Diffraction grating mount |
